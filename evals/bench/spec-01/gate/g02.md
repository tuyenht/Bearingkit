# Reopen closed tickets

## Summary

Customers will be able to reopen a closed ticket from the portal within 14 days of it being closed. The assigned agent is notified when this happens.

## Requirements

1. The ticket page in the portal shows a "Reopen" button on closed tickets.
2. The button is available for 14 days after the ticket was closed and is hidden afterwards.
3. Pressing the button sets the ticket to open.
4. The assigned agent receives a notification.

## Testing

- Unit tests for the new function.
- A test that the button is hidden after 14 days.
