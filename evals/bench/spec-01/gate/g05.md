# Reopen a closed ticket (portal)

## Goal

Let a customer reopen a closed ticket within 14 days and notify the assigned agent.

## Security

A customer may only reopen tickets that belong to their own organisation. A request for any other ticket is rejected exactly as if the ticket did not exist.

## Open questions

1. Do agents currently have a way to reopen tickets? Recommended: assume they do not and build it.
2. Should the reopen restart the SLA clock? Recommended: no, keep the original due time so reports stay comparable.
3. Should we limit how often a ticket can be reopened? Recommended: three times.
4. Should the customer be asked for a reason? Recommended: yes, required.
5. Should the agent be able to refuse the reopen? Recommended: no.
6. Should the button appear in the ticket list as well as on the ticket page? Recommended: ticket page only.
7. Should we send the customer a confirmation email? Recommended: yes.

## Requirements

- Button on the ticket page for 14 days after closing.
- Status goes to open.
- Assigned agent is notified.
