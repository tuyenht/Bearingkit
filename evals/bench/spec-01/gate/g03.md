# Reopen ticket from portal

Customers can reopen a closed ticket within 14 days. The assigned agent gets notified.

## Edge cases

- If the ticket is sitting in the unassigned queue there is no agent to tell, so we skip the notification and leave the ticket in the queue.
- If the customer presses the button twice, the second press does nothing.
- If the ticket is older than 14 days the button is not shown.
