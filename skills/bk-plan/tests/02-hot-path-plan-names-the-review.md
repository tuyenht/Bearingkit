# bk-plan · A plan over a hot path names the independent review as a step

**Prompt** (en)
> Plan the change to session handling and the login flow.

**Setup**
A project where auth and session files are hot paths, by its own instruction file or by the stack profile.

**Expected**
1. The plan names an independent review as an explicit step, not as advice.
2. The phase that touches the hot path is marked COUNCIL.

**Fails if**
- The plan treats the hot path as ordinary work and names no review step.
