# bk-design · The plan is reviewed against the brief before code starts

**Prompt** (en)
> Design a landing page for a tool that tracks bearing wear in industrial pumps.

**Setup**
Any project, with no design system of its own.

**Expected**
1. The subject, the audience and the primary job are named in one line each, or proposed and confirmed when the brief left them open.
2. A plan is written first: four to six named hex values, typefaces with roles, a layout concept with an ASCII wireframe and an alignment decision, and the principles specific to this screen.
3. The plan is then reviewed against the brief, and what the review changed is stated with the reason.
4. Only after that review does any code appear.

**Fails if**
- Markup or CSS is written before the plan exists.
- The plan is written and built from with no review pass and no statement of what changed.
