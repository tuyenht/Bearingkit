### Lessons from these sessions (candidate lines for the kit's own lessons log)

- RULE | process | WHEN a skill default names a folder or file THEN follow the repository's convention NOT the skill's | evidence: `docs/superpowers/` created and reverted | 2026-09-09
- RULE | safety | WHEN a tool call would print environment values or a diff of a file that may hold credentials THEN redact secret-looking values first NOT print raw | evidence: two leaks in one session | 2026-09-09
- RULE | scope | WHEN the owner names a project as a source of lessons THEN read what they point at NOT other systems, even read-only | evidence: server inspection retracted | 2026-09-09
- RULE | evidence | WHEN a number comes from a web-research agent THEN quote it only after local verification NOT as a fact | evidence: star counts and a version were wrong | 2026-09-09
- RULE | review | WHEN a spec has been rewritten by its author more than twice THEN get an independent reader NOT another self-audit | evidence: two independent reviews found 40 buildability gaps after four self-audits | 2026-09-10
- RULE | measurement | WHEN a host measurement looks wrong THEN list every file the host could have loaded from the working directory upward NOT only the files the kit installed | evidence: 71.9k memory tokens in an "isolated" session came from the ancestor's `.claude/` | 2026-09-10
- RULE | quota | WHEN a check could spawn a host session THEN use a flag that returns before spawning NOT a code path that may not be in place yet | evidence: a refusal check ran before the refusal existed and spent one session at 97% of the window | 2026-09-10
- RULE | hooks | WHEN a hook injects context into the message THEN close the block with a marker and say in the protocol that the rest is the request NOT leave the block open | evidence: a one-line bug report after the block was read as context twice | 2026-09-10
- RULE | evals | WHEN sessions share a working copy THEN reset it before every prompt NOT trust the model to leave it clean | evidence: the previous setup edited and committed the fixture, later prompts saw the diff | 2026-09-10
- RULE | evidence | WHEN a host mechanism is recorded as "verified from docs" THEN keep the quoted excerpt and its location beside the claim NOT a paraphrase | evidence: the plugin registry claim was recorded as verified and was wrong | 2026-09-10
- RULE | hooks | WHEN a probe hook is placed in a live host THEN register it only on events whose contract accepts an empty reply NOT on events that require a decision | evidence: a PreToolUse probe answering `{}` could have changed what the owner's real sessions may do | 2026-09-10
- RULE | tests | WHEN a test installs or uninstalls THEN point it at a temporary copy of the kit NOT at the checkout a live dev-mode link targets | evidence: the installer tests deleted the generated files the live Antigravity plugin was serving | 2026-09-10
- RULE | skills | WHEN a frontmatter value contains ": " THEN quote it NOT rely on the lenient parser of one host | evidence: Antigravity 2.0 dropped ten of eleven skills that Claude Code had accepted | 2026-09-10
- RULE | hosts | WHEN a host ships as more than one product THEN name the product in every measurement NOT "the host" | evidence: the same disk state read as "not loaded" on the IDE and "loaded" on 2.0 | 2026-09-10
- RULE | hosts | WHEN a host discovers plugins by scanning a directory THEN test a junction before relying on one NOT assume the scanner follows links | evidence: junction listed nothing, copied directory listed eleven skills, same panel minutes apart | 2026-09-11
- RULE | evals | WHEN a driver runs many prompts THEN retry one failed prompt after a pause NOT end the run | evidence: a composer race ended a 42-prompt run at prompt six | 2026-09-11
- RULE | evals | WHEN a positive prompt names a thing THEN the fixture holds it NOT rely on the model to read the skill before it searches | evidence: `sm-en-04` asked for a message that did not exist; Antigravity's model searched, found nothing, never opened `bk-build` | 2026-09-11
- RULE | measurement | WHEN a token reading is compared before and after a change THEN take the "before" on the same host version, day and profile state (stash the change, measure, restore) NOT reuse an earlier reading | evidence: the first reading of the day sat 1,033 tokens below three later ones at an unchanged kit; only the stashed-state reading proved the port cost nothing | 2026-09-11
- RULE | measurement | WHEN a "should cost nothing" assumption is checked THEN remove the thing and measure NOT reason from the design | evidence: hiding the seven `references/` directories moved the reading by 2 tokens; the number that had moved was unrelated | 2026-09-11
- RULE | tools | WHEN a file to write exceeds a few kilobytes THEN use the Write tool NOT a Bash heredoc | evidence: three long heredocs failed with "unexpected EOF"; the short one succeeded | 2026-09-11
- RULE | quota | WHEN a measurement plan needs several host sessions THEN state the count and expect the account limit NOT assume an isolated profile has its own window | evidence: two runs refused at 10:19 by the shared session limit | 2026-09-11
