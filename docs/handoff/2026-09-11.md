### Lessons (candidate lines for the kit's lessons log)

- RULE | tools | WHEN a Bash command would carry a heredoc of more than a few kilobytes or a heredoc plus quoted perl THEN write the file with the Write tool and run programs from files NOT inline | evidence: four long commands failed at parse time on 2026-09-11, running nothing | 2026-09-11
- RULE | measurement | WHEN a token reading is compared before and after a change THEN take the "before" on the same host version and day with the change stashed NOT an earlier reading | evidence: a 1,033-token outlier came from host feature flags, not the kit | 2026-09-11
- RULE | hosts | WHEN a host can load a plugin from a directory THEN test with that flag before building any install mechanism NOT after | evidence: `--plugin-dir` made the whole v1 installer unnecessary | 2026-09-11
- RULE | scope | WHEN a proposal claims the hard part is done THEN name what is done and what is not in numbers NOT a summary | evidence: "the hard part is done" was retracted in the audit: one of about thirty sources absorbed | 2026-09-11
- RULE | refactor | WHEN a new mechanism replaces an old one THEN diff what the new one produces against what the old one produced NOT only check that it produces something | evidence: the v2 Antigravity copy dropped the host note the v1 installer had appended; the feature prompt failed exactly as on 2026-09-10 | 2026-09-11
- RULE | hosts | WHEN a skill tells the model to run a script from `<kit>` THEN the bootstrap states the kit path on that host NOT assume the model can infer it | evidence: the injected protocol carried no path, and the Antigravity copy carried no scripts at all | 2026-09-11
- RULE | harness | WHEN a driver targets a local server THEN read its origin from the running page NOT hard-code the port | evidence: the app's UI port was 1407 one day and 29065 the next; three retries burned before the cause was seen | 2026-09-11
- RULE | monitoring | WHEN a watch greps a log for a terminal marker THEN scope it to lines written after the watch started NOT the file's last line | evidence: a stale "driver error" line ended a monitor before the new driver had written anything | 2026-09-11
- The seventeen earlier lessons from 2026-09-09 to 2026-09-11 (skill defaults versus repo conventions, secret redaction, scope, verified numbers, independent readers, ancestor memory files, quota-safe checks, closed injection blocks, fixture resets, quoted excerpts, probe events, temp copies for install tests, quoted frontmatter, product naming, junction tests, driver retries, fixture targets) stand; they are in the morning handoff in git history and belong in the lessons log when it exists.
