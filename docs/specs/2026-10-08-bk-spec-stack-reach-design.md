Under "Steps", a new step 1, the present steps 1 to 5 becoming 2 to 6: "**Stack rules before anything else.** Run `detect-stack` from the project root, unless its output is already in this session, and open every file it lists under `stackFiles` before reading the code; an empty list is said, not skipped."
