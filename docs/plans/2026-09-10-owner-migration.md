Status: PLANNED · Applies to: the kit author's machine only · Spec: `docs/specs/2026-09-11-bearingkit-v2-design.md` (Phase 0 unchanged; from Phase 2 on, "install" means the host's own plugin install: Claude Code marketplace or `--plugin-dir`, Antigravity `bearingkit install --host antigravity`, which writes the store, followed by `bearingkit activate` in each project that should use the kit — measured on the app 2026-09-20, `docs/compat/2026-09-19-per-project-activation.md`; there is no kit installer, no links, no kit entries in host settings)
