### Added (2026-09-20)
- Per-project activation (D5 question 29): one verb set for every host — `bearingkit install`, `update`, `activate`, `deactivate`, `status`, `uninstall`, each with `--host all|antigravity|claude`, a project path, `--dry-run`, and the same `+ / - / =` lines.
